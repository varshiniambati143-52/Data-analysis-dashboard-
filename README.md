# Sales & Revenue Analysis Dashboard

## 1. Project Title / Headline

**Sales & Revenue Analysis Dashboard**

An interactive Power BI dashboard designed to analyze sales performance, revenue trends, product performance, and regional sales using visual analytics and interactive filters.

---

## 2. Short Description / Purpose

The Sales & Revenue Analysis Dashboard is a Power BI-based business intelligence project that provides a clear and interactive view of sales data. The dashboard helps users understand total sales, average sales, sales trends, top-performing products, category performance, regional performance, and sub-category sales.

It is designed to support data-driven analysis and help identify important business trends and performance areas.

---

## 3. Tech Stack

The dashboard was created using the following tools and technologies:

- **Microsoft Power BI Desktop** – Used to create the interactive dashboard and visualizations.
- **Power Query** – Used for importing and preparing the sales data.
- **DAX** – Used to create calculated measures such as Average Sales.
- **Excel** – Used as the source data file.
- **Power BI Visualizations** – Used to create KPI cards, charts, slicers, and tables.

---

## 4. Key Features

- Total Sales KPI
- Average Sales KPI
- Sales Trend Analysis
- Top 10 Performing Products
- Sales by Category
- Sales by Region
- Sales by Sub-Category
- Interactive Region filter
- Interactive Year filter
- Product-level sales details
- Interactive dashboard visualizations

---

## 5. Dashboard Insights

The dashboard provides insights into:

- Overall sales performance
- Sales trends over time
- Products generating the highest sales
- Category-wise sales contribution
- Regional sales performance
- Sub-category performance
- Detailed product-level sales information

---

## 6. Expected Outcome

This project demonstrates how Power BI can be used for **data visualization, KPI tracking, interactive analysis, and business insight generation**. It helps users transform raw sales data into meaningful visual information for better decision-making.
